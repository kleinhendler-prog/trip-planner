# Glossary

Project-specific terms. Reference when a term in code or conversation is unclear.

---

## How to maintain this file

- Only add a term if it's project-specific (used here in a way different from common usage) or non-obvious.
- One line per term. Definition should be clear to a non-coder reading it cold.
- If a term falls out of use, remove it — don't keep dead entries.
- Don't define common programming terms (function, variable, API, etc.).

---

## Terms

- **Sources** — curated travel-info sources (guides, blogs) attached to a destination; users vote them up/down. Stored in the `destination_sources` table; "universal" sources apply everywhere, others are per-destination (Italy is seeded).
- **QA simulator** — the last step of the generation pipeline: the model reviews the finished itinerary for problems (timing, feasibility) before it's shown to the user.
- **Stitch kit** — the UI design package in `stitch-design/`, generated by Google Stitch from `stitch-prompt.md`; the visual source of truth.
- **Reflection** — the post-trip feedback flow where the traveler records what worked and what didn't (`trip_reflections` table).
- **Booking urgency** — the Must Book / Book Ahead / Walk-in OK label on an activity, telling the traveler whether advance reservation is needed.
