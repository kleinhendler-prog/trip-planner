# Glossary

Project-specific terms. Reference when a term in code or conversation is unclear.

---

## How to maintain this file

- Only add a term if it's project-specific (used here in a way different from common usage) or non-obvious.
- One line per term. Definition should be clear to a non-coder reading it cold.
- If a term falls out of use, remove it — don't keep dead entries.
- Don't define common programming terms (function, variable, API, etc.).

---

## Terms

- **Sources** — curated travel-info sources (guides, blogs) attached to a destination; users vote them up/down. Stored in the `destination_sources` table; "universal" sources apply everywhere, others are per-destination (Italy is seeded).
- **Simple pipeline** — the active generation path (`simple-pipeline.ts`): one Claude call produces the whole itinerary as JSON, then QA validation runs on it. Replaced the original 7-step pipeline.
- **QA simulator / QA validation** — 13 automated checks on a generated itinerary (empty days, schedule conflicts, geographic zigzags, missing coordinates, venue closure days, etc.); results stored with the trip.
- **Segment** — one leg of a multi-segment trip (a city stay, an area, or a road trip); each segment is generated separately and stitched into one itinerary.
- **Local find** — a day-scoped small discovery (tasting, shop, market, workshop) shown in "While You're in the Area".
- **Stitch kit** — the UI design package in `stitch-design/`, generated by Google Stitch from `stitch-prompt.md`; the visual source of truth, implemented as CSS tokens in `globals.css`.
- **Reflection** — the post-trip feedback flow where the traveler records what worked and what didn't (`trip_reflections` table).
- **Booking urgency** — the Must Book / Book Ahead / Walk-in OK label on an activity, telling the traveler whether advance reservation is needed.
- **local-cowork-snapshot** — git branch preserving the stale local folder state (and Cowork leftovers like deploy.sh) from before the 2026-07-03 sync with GitHub.
